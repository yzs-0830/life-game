# 留一手：人生的路口

一個用來思考「保留策略彈性」的人生選擇小遊戲。玩家從童年走到晚年，在每個階段做選擇，累積知識、健康、財富、人際、幸福與**彈性**，並在途中培養技能、遇到無法預料的人生變局，最後看看自己走出了什麼樣的人生。

## 怎麼玩
1. 打開 `index.html`（或 GitHub Pages 連結）。
2. 選擇是否顯示「彈性」數值，按下開始。
3. 每個階段會遇到一個情境，從四個選項中選一個。有些選項需要條件才能選，有些結果靠機率。
4. 人生中會出現命運卡（個人事件或環境事件），結果取決於你之前的準備。
5. 走到最後會看到你的評價、稱號、數值變化圖，以及每個關鍵時刻的回顧。

## 設計想法
- **彈性** 代表「還能轉彎的空間」。專精能換來更高的成就，但路會變窄；保留彈性成長較慢，卻比較能應付變局。
- 最佳策略不是永遠不做決定，而是在承諾之前先保留選擇權，等條件成熟再專精。
- 技能分為專精型與通用型。越高階的技能需要越多次連續投入，也會壓低彈性上限。
- 結局沒有絕對的對錯，但有社會價值觀上的好與不好。結局頁會列出你錯過的選項，方便課堂討論。

## 部署到 GitHub Pages
全部是靜態檔案，不需要建置，所有路徑都是相對路徑，放在任何子路徑下都能運作。

1. 在 GitHub 建立 repo（Public；免費帳號的 Pages 需要公開 repo），把本資料夾推上去。
2. 進入 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。repo 名稱就是網址的最後一段，例如 repo 取名 `life-game`，網址就是 `https://<你的帳號>.github.io/life-game/`。
4. 若 repo 取名為 `<你的帳號>.github.io`，網址會直接是 `https://<你的帳號>.github.io/`。

成就收藏存在玩家自己瀏覽器的 `localStorage`（鍵名 `lg_achv_v1`），綁定網址（origin），換瀏覽器或清除網站資料就會消失。

## 檔案結構
```
index.html          入口
css/                樣式（base 基礎、layout 版面、components 元件、events 命運卡、ending 結局）
js/engine/          遊戲邏輯（純邏輯，不碰 DOM）
js/ui/              畫面渲染
data/               所有內容：設定、技能、結局、questions/（題庫）、events/（事件）
tools/              資料檢查、隨機模擬、題庫覆蓋、文字一致性檢查（需要 node，只在開發時使用）
docs/               PLAN.md 開發計畫與檢核；SCHEMA.md 資料格式；FLAGS.md 旗標；ACHIEVEMENTS.md 成就設計
```

## 開發工具
```bash
node tools/validate.js        # 檢查資料格式與引用
node tools/simulate.js 5000   # 隨機模擬 5000 局，檢查流程、事件規則、身分合理性與結局分布
node tools/coverage.js        # 檢查各身分在各年齡段的題庫是否足夠
node tools/audit.js 6000      # 檢查文案與身分是否一致（不會有教授被主管問升遷、單身的人被孩子問問題）
node tools/monotone.js 3000   # 單調性：任何一項數值變高，分數都不會變低
node tools/routes.js 24 10    # 各路線的理論天花板表（平行執行 optimize.js，約 15–25 分鐘），可加 --routes=med,law 只跑部分
node tools/optimize.js 24 6 0.3 --goal=med   # 單一路線的最強人生搜尋（貪心＋蒙地卡羅），印出完整的選擇紀錄
```
`validate.js` 會用 `tools/lint.js` 做靜態的文字一致性檢查，`simulate.js` 也會在模擬時檢查每一段顯示出來的文字。想在本機試玩，可以直接開 `index.html`，或在專案資料夾執行 `python3 -m http.server 8765` 後開 `http://localhost:8765`。
詳細的階段與檢核項目見 [docs/PLAN.md](docs/PLAN.md)，資料格式見 [docs/SCHEMA.md](docs/SCHEMA.md)。

## 目前進度
科系與職業聯動全部完成：36 個時間槽、323 張題卡、40 張事件、6 條技能線、24 個結局稱號。八個科系各有大學、畢業分岔、職涯與老年的專屬題；環境事件與個人事件會依科系與專業身分給出不同的結果；結局頁有人生稱號、六個面向的評價、成就與身分軌跡。詳細的開發過程與檢核結果見 [docs/PLAN.md](docs/PLAN.md)。

彈性強化（已完成，階段 1–4）：彈性高的人會看見隱藏的「另闢蹊徑」選項（50 個）、遇到高彈性專屬題，失敗時損失較小；彈性低的人會遇到困境題，轉換領域與跑道的選項會因「彈性不足」被鎖住（81 個）；機率判定與個人事件都依彈性分流；連續專精與長期忙碌會讓彈性慢慢下降，持續保留選擇權則回升。每個人都會遇到一次婚姻抉擇，人緣越高越早出現。

成就系統：共 293 項成就，分銅、銀、金、白金、隱藏五個等級；成就會跨局累積（存在瀏覽器的 localStorage），標題頁有成就圖鑑，結局頁會標示本局新解鎖的成就。設計與條件見 [docs/ACHIEVEMENTS.md](docs/ACHIEVEMENTS.md)。
