# 成就系統擴充設計

目標：成就從 47 項擴充到約 **150 項**，分五個等級，並讓成就跨局累積。
舊成就的 `id` 全部保留，只補上 `tier` 欄位，新成就依下表新增。

## 一、等級

| 等級 | 代號 | 意義 | 目標數量 | 點數 | 解鎖難度（隨機選擇下每局觸發率） |
|---|---|---|---|---|---|
| 銅 | `bronze` | 日常：走過一般人生就會遇到 | 40 | 1 | 15%–60% |
| 銀 | `silver` | 不凡：做過某個明確的選擇或達成某個里程碑 | 45 | 2 | 4%–15% |
| 金 | `gold` | 稀有：需要專精路線、特定連鎖或高數值 | 35 | 4 | 0.5%–4% |
| 白金 | `platinum` | 傳奇：極端數值、完整長鏈、多條件同時成立 | 15 | 8 | < 0.5%（允許在指導式策略下才出現） |
| 隱藏 | `hidden` | 隱藏：條件不公開，達成才顯示（涵蓋低谷、反差與彩蛋） | 15 | 6 | 不限 |
| 合計 | | | 150 | | |

規則：
- 同一條成就鏈（例如「博士畢業」→「學術大師」）高階者要比低階者嚴格，且低階不因高階解鎖而消失（兩者都顯示）。
- 隱藏成就在未解鎖時，只在清單中顯示「？？？」與所屬分類，不顯示條件。
- 每個等級用不同的顏色與徽章；結局頁依等級由高到低排序。

## 二、跨局收藏（新增）

100 多個成就不可能在一局拿完，所以需要跨局累積：
- 用 `localStorage`（鍵名 `lg_achv_v1`）記錄每個成就的首次解鎖日期與解鎖次數。讀寫都包 try/catch，讀不到就退回單局顯示。
- 結局頁：本局成就（新解鎖的標「NEW」）＋ 收藏進度（總數、各等級完成度、成就點數、稱號）。
- 標題頁新增「成就圖鑑」：依分類與等級瀏覽，已解鎖顯示解鎖局的結局稱號，未解鎖的銅、銀、金顯示條件提示，隱藏顯示「？？？」。
- 成就點數累積後給收藏家稱號（見第五節）。
- 提供「重設收藏」按鈕。

## 三、資料格式

```js
{ id, tier: 'bronze'|'silver'|'gold'|'platinum'|'hidden', group, name, text, when, hint? }
```

- `hint`：圖鑑中未解鎖時顯示的提示（預設隱藏成就不顯示）。
- `when` 沿用現有條件（`min`、`flags`、`anyFlags`、`skills`、`profession`、`major`、`intMin`、`ctrMin`…）。
- 需要新增的條件欄位，原則上都以現有旗標與狀態湊出來；湊不出來的才新增旗標（見第六節）。
- 新增兩個少量的條件欄位：
  - `ending`：結局稱號 id（可為陣列），用於「獲得某稱號」的成就。
  - `grade`：最低綜合等級（`S`/`A`/`B`/`C`），用於等級類成就。
  - `flexLog`：`{ hiddenTaken: n, saved: n, softMin: n }`，用於彈性類成就。
  - `ageAtFlag`：`{ 旗標: [最小年齡, 最大年齡] }`，用於「早結婚」「晚婚」等；需要在設定旗標時記錄年齡（`st.flagAge`）。

## 六、需要新增的旗標與資料

- 新旗標（題目中設定）：`pet`、`remarried`、`marriage_saved`、`invest_win2`、`elder_clean`。其他成就都可以用現有旗標、數值或 `st.history` 湊出來。
- 新狀態：`st.flagAge`（設定旗標時記錄年齡，用於早婚、晚婚）。
